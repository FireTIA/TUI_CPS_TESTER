# TUI CPS Tester

Консольная (TUI) утилита для Windows, которая измеряет скорость кликов мышью (**CPS — Clicks Per Second**) и анализирует стабильность ритма кликов.

Проект сделан **для своих целей** — как небольшой личный инструмент, а не как продукт для широкого использования.

## Что делает программа

- Отслеживает клики мыши в реальном времени через низкоуровневый хук Windows (`WH_MOUSE_LL`, `user32.dll`).
- Позволяет выбрать, какую кнопку отслеживать: ЛКМ, ПКМ, СКМ (колесо) или любую.
- Запускает тест заданной длительности с отсчётом "3, 2, 1" перед стартом.
- Во время теста показывает live-счётчик кликов и текущий CPS.
- По окончании теста выводит подробную статистику:
  - Средний CPS за весь тест
  - Средний / минимальный / максимальный интервал между кликами
  - Джиттер (стандартное отклонение интервалов) — показатель стабильности ритма
  - Текстовую гистограмму распределения интервалов между кликами

## Технические детали

- **Платформа:** Windows (использует `user32.dll` / `kernel32.dll` через P/Invoke)
- **Фреймворк:** .NET 10.0, консольное приложение (x64)
- Обработка хука мыши вынесена в отдельный поток со своим message loop — это обязательное требование Windows для корректной работы `WH_MOUSE_LL`. Без этого весь ввод мыши в системе начинает лагать.
- Обработчик клика (`HookCallback`) выполняется синхронно для каждого события мыши в системе, поэтому не содержит блокировок, аллокаций и вывода в консоль — только запись в `ConcurrentQueue` (lock-free).
- Временные метки кликов хранятся в тиках `Stopwatch` и переводятся в миллисекунды при подсчёте статистики — для повышенной точности.

## Как использовать

1. Собрать и запустить проект (Visual Studio / `dotnet run`).
2. В главном меню выбрать кнопку мыши для отслеживания (по умолчанию — ЛКМ).
3. Запустить тест, указать длительность в секундах.
4. Кликать мышью (вручную или с помощью автокликера) во время записи.
5. Посмотреть результаты: CPS, интервалы, джиттер и гистограмму.
